# PanCancer_TumorReactiveT
This repository contains codes for analysis of the pan-cancer immunotherapy scRNA-seq data.

All data are included in the Supplementary Information or available from the authors, as are unique reagents used in this Article.

Any additional information required to reanalyze the data reported in this paper is available from the lead contact upon request.

Please contact wangcy1@sysucc.org.cn, or zhaoqi@sysucc.org.cn with any questions.
